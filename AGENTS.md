# AGENTS.md — Kontaktu Contact Challenge

## Project

Build a contact management experience for **Kontaktu**, an AI-first real-estate CRM where contacts come from multiple channels such as phone calls, WhatsApp conversations, web forms, marketing campaigns, CRM imports, and manual entry.

The main focus is a robust **contact detail page** that allows real-estate agents to quickly understand a contact before reaching out. The interface must handle heterogeneous and incomplete data, dynamically render qualification information, preserve data provenance, and display interactions such as calls, WhatsApp messages, and form submissions in a chronological timeline.

The application uses **Next.js (App Router), React, TypeScript, and Tailwind CSS**, with the provided JSON data exposed through an API or server boundary.
